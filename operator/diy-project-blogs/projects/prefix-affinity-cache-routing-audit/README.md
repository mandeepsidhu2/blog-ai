Dependency-free matched simulation of worker-local prefix-cache routing. Run `node run-experiment.mjs` to regenerate repeat-level metrics, aggregate results, the claim table, result figure, and SHA-256 ledger.

No model service or Torch runtime is used. The result applies only to the declared simulation contract in `config.json` and `research-log.md`.
